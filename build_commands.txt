 Build first:                                                                                                      
  go build -o thinbox ./cmd/thinbox/                                                                              
                                                                                                                    
  Then run:                                                                                                         
  sudo ./thinbox run alpine /bin/sh                                                                                 
                                                                                                                 
  But there's a catch — you're on WSL2.
                                                                                                                    
  The run command re-execs the binary via /proc/self/exe after clone(2). WSL2 blocks this, so run will fail locally.
   It only works in CI on a real Ubuntu VM.                                                                         
                                                                                                                    
  What you can run locally:                                                                                      
  ./thinbox help        # always works
  sudo ./thinbox ps     # works (reads state dir)



  #### tests
  Locally (WSL2) — only non-Linux tests:                                                                            
  # Install RF if needed                                                                                            
  pip install robotframework                                                                                        
                                                                                                                    
  # Run only tests that don't require a real kernel                                                                 
  sudo $(which robot) --exclude requires-linux --outputdir results tests/
